# Custom Odoo 19 addons

این پوشه برای ماژول‌های اختصاصی پروژه در شاخه `development/community-customization` در نظر گرفته شده است. هنوز هیچ ماژول اجرایی در آن وجود ندارد.

- کد و مجوز هسته Odoo Community را حفظ کنید؛ برای سفارشی‌سازی تا حد امکان ماژول مستقل ایجاد کنید.
- هر ماژول باید فایل `__manifest__.py`، وابستگی‌های مشخص و قواعد دسترسی و آزمون‌های متناسب داشته باشد.
- بارگذاری این مسیر خودکار نیست؛ هنگام نصب و اجرای محلی آن را در `addons_path` لحاظ کنید.
- اطلاعات محرمانه، داده واقعی و فایل‌های پیکربندی حاوی رمز را ثبت نکنید.

راهنمای واحد فرایند توسعه و وضعیت فعلی: [`CUSTOM_DEVELOPMENT.md`](../CUSTOM_DEVELOPMENT.md).
